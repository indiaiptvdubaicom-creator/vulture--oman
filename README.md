# Vulture Events Oman

Independent premium event-management website for the **Oman** market.

**Brand:** Vulture Events Oman  
**Primary market:** Oman · **Primary city:** Muscat  
**Stack:** Next.js App Router, TypeScript, Tailwind CSS  
**Local preview:** `npx next dev -p 3002`

## Run locally

```bash
npm install
npx next dev -p 3002
```

Production build:

```bash
npm run build
npx next start -p 3001
```

Set `NEXT_PUBLIC_SITE_URL` to the public Oman domain before launch.

## Absolute rules

- Zero non-Oman market content, stats, testimonials, clients, venues, or phone numbers unless the owner later supplies an approved number.
- No fabricated projects, clients, results, or testimonials.
- Contact details stay empty until real Oman NAP is supplied.
- Arabic is architected for event delivery; the published site is English-first.
